# @fairgarden/id

One account for every service in a FairGarden deployment.

People sign in with a passkey, or with a code sent to their email, and decide
service by service what each one may see. The id service keeps only what is
sensitive or has to be verified — an email address, a name, a phone number,
mailing and residential addresses. Everything else about a person belongs to
the services themselves, which can pass their own claims to each other
through this one, with the person's say-so.

It is an OpenID Connect provider, built on
[oidc-provider](https://github.com/panva/node-oidc-provider), so any service
that speaks OIDC can sign in with it.

## Run it

```bash
pnpm dev            # http://localhost:3010
```

Nothing else is needed locally: an embedded Postgres starts in `.data/id`,
and email goes to the mock mailbox at `/dev/mailbox`.
