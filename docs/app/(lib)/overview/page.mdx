## Policy

Every authorization decision the id service makes goes through
`lib/server/policy.ts`, which uses
[@fairgarden/policy](https://github.com/fairgarden/policy): each decision is
asked the way Open Policy Agent expects, so the built-in rules can be replaced
by Rego without touching anything that asks, and every one is recorded.
